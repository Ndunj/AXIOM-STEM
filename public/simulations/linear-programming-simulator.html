Linear Programming: Instructional Guide

Core Concepts for Students and Educators

What is Linear Programming?

Linear Programming (LP) is a mathematical technique used to find the best possible outcome (such as maximum profit or minimum cost) in a given mathematical model whose requirements are represented by linear relationships.

Maximization vs. Minimization

Profit Maximization: Constraints are typically resource capacities (≤), bounding the feasible region near the origin. We look for the highest vertex value.
Cost Minimization: Constraints are typically minimum requirements (≥), forming an unbounded region pushing outward from the origin. We look for the lowest vertex value.

The Feasible Region

The shaded region on the plot represents the Feasible Region. Every point (x, y) inside or along the boundary of this area satisfies all given resource or requirement constraints simultaneously as well as non-negativity (x ≥ 0, y ≥ 0).

The Corner Point Theorem (Fundamental Theorem of LP)

If an optimal solution exists for a linear program, it will always occur at one of the vertices (corner points) of the feasible region. This allows us to evaluate the objective function Z only at the vertices rather than testing infinite interior points.

The Iso-Profit / Iso-Cost Line

The dotted line on the graph represents the objective function Z. Sliding this line outwards (for profit) or inward towards the origin (for cost) until it leaves the feasible region reveals the optimal corner point.
