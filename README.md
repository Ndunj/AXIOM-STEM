# AXIOM STEM — Interactive STEM Simulation Marketplace & Virtual Labs

AXIOM STEM is an educational platform providing interactive, standards-aligned (NGSS, AP, IB, CCSS) simulations and virtual laboratory suites across Physics, Mathematics, Chemistry, and Biology, complete with AI-powered inquiry lesson planning and real-time worksheet generation.

---

## 🌟 Key Features

- **Multi-Discipline STEM Simulations**:
  - **Physics**: Projectile Motion, Simple Harmonic Motion, Optics, Circuits, Thermodynamics, Special Relativity, Wave Interference, and more.
  - **Chemistry**: Periodic Trends, Acid-Base Titrations, Gas Laws, Reaction Kinetics, Chemical Bonding, and Electrochemistry.
  - **Biology**: Natural Selection & Population Genetics, Cell Membrane Transport & Osmosis, Mitosis vs. Meiosis, Mendelian & Non-Mendelian Genetics, DNA Replication & Protein Synthesis.
  - **Mathematics**: Functions & Transformations, Calculus (Derivatives & Integrals), Vectors & Matrix Transformations, Probability & Statistics, Linear & Quadratic Systems.
- **Inquiry Lab Worksheets**: Real-time downloadable worksheets with student data tables, critical thinking prompts, model answer keys, and real-world scientific scenarios.
- **AI Lesson Plan Generator**: Instant customized lesson plans aligned to specific curriculum standards.
- **Classroom & District Licensing**: Tiered licenses for individual educators, departments, and entire school districts with secure checkout integration.
- **Firebase Authentication & User Accounts**: Secure user sign-in and cloud state persistence.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Motion (Framer Motion), Lucide React
- **Backend & APIs**: Node.js, Express, Google Gen AI SDK
- **Build Tool**: Vite, esbuild
- **Document & PDF Generation**: jsPDF, jspdf-autotable, docx

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Create a `.env` file based on `.env.example`:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```

The application will be accessible at `http://localhost:3000`.

### 4. Production Build
```bash
npm run build
npm start
```
